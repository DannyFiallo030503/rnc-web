# Provincias de Cuba

Geometría original simplificada de geoBoundaries, CUB ADM1, revisión `9469f09`.
Fuente de límites: OpenStreetMap / Wambacher. Año representado: 2017.
Incluye 15 provincias y el municipio especial Isla de la Juventud.

- Descarga: https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/CUB/ADM1/geoBoundaries-CUB-ADM1_simplified.geojson
- Metadatos: `cuba-provinces.metadata.json`.
- Licencia declarada por la fuente: Open Database License 1.0, https://opendatacommons.org/licenses/odbl/1-0/.
- Atribución: © OpenStreetMap contributors; Wambacher; geoBoundaries (https://www.geoboundaries.org/).

El archivo geográfico se conserva sin modificar. La aplicación proyecta sus
coordenadas únicamente para la representación y enlaza explícitamente los nombres
geográficos con las provincias del catálogo del portal. No contiene datos clínicos.
Esta cartografía es una fuente de visualización externa, pendiente de cotejo con
la cartografía institucional del RNC.
