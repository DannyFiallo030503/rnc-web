{% translate "El Registro Nacional de Cáncer" %}

{% translate "El Registro Nacional de Cáncer de Cuba (RNC) es de base poblacional y alcance nacional, y forma parte del sistema de información estadística del Ministerio de Salud Pública. La copia archivada del sitio institucional indica que fue creado en 1964, que perteneció al Instituto Nacional de Oncología y Radiobiología (INOR) hasta diciembre de 2007 y que, desde enero de 2008, se subordinaba metodológica y funcionalmente a la Sección Independiente de Control de Cáncer junto con el Programa Integral de Control de Cáncer en Cuba." %}

{% translate "La adscripción organizativa debe actualizarse con el RNC: el" %} {% translate "Sistema de Información Estadística Complementaria de Salud (2017)" %} {% translate "transcribe la Resolución 31/2008 como traslado de la Oficina Central a la Unidad Nacional para el Control del Cáncer, bajo su dirección y en coordinación con Estadísticas del MINSAP. Las denominaciones de las fuentes no coinciden literalmente." %}

{% translate "Objetivos" %}

{% translate "Qué hacemos" %}

{% translate "Objetivo principal:" %} {% translate "describir la magnitud del cáncer como problema de salud en Cuba." %}

{% translate "Para ello, la información institucional de referencia atribuye al RNC estos objetivos específicos:" %}

  • {% translate "Emitir frecuencias y tasas de incidencia específicas por edad y sexo para cada localización topográfica y morfológica, además de tasas ajustadas para Cuba y cada provincia." %}
  • {% translate "Estimar las cifras de supervivencia poblacional por cáncer." %}
  • {% translate "Emitir frecuencias absolutas y relativas por localización según la etapa clínica al diagnóstico, la provincia y la unidad informante, la base más válida para el diagnóstico y otras variables de interés." %}
  • {% translate "Calcular indicadores de calidad de los datos por provincia y localización." %}

{% translate "La información del RNC también contribuye a la investigación clínica y epidemiológica sobre el cáncer, a planificar y evaluar las acciones de control, y a planificar los recursos materiales y humanos para la atención oncológica." %}

{% translate "Este portal ofrece actualmente consultas estadísticas de incidencia. No presenta aquí resultados de supervivencia, etapas clínicas, bases diagnósticas ni indicadores de calidad del RNC." %}

{% translate "Alcance nacional" %}

{% translate "Dónde trabajamos" %}

{% translate "El RNC es un registro de base poblacional con cobertura de residentes permanentes de Cuba. Su red se organiza en tres niveles: la Oficina Central, los equipos o registros provinciales y las unidades informantes que detectan y notifican los casos." %}

{% translate "La cobertura documentada comprende las 15 provincias y el municipio especial Isla de la Juventud. En los territorios, los departamentos de salud coordinan las unidades informantes; estas incluyen centros hospitalarios y otras fuentes asistenciales previstas por los procedimientos del Registro." %}

{% translate "La red territorial permite reunir información de distintos puntos de atención y consolidarla con alcance nacional. La copia del sitio institucional organiza esa red con una comisión o registro de cáncer en cada provincia y un directorio territorial de responsables." %}

{% translate "El directorio que se reproduce en esta página procede de una copia histórica del sitio: la información de Oficina Central fue publicada en 2013 y el directorio provincial en 2015. Se muestra como referencia histórica; sus nombres y canales no están confirmados como vigentes." %}

{% translate "Organización" %}

{% translate "Cómo trabajamos" %}

{% translate "La copia histórica describe una Oficina Central y comisiones provinciales que asesoran a las autoridades de salud y apoyan la aplicación de los procedimientos. El Manual de Procedimientos del RNC, versión VII (2024), detalla el recorrido operativo de la información:" %}

  1. {% translate "Detección y notificación:" %} {% translate "los médicos notifican los casos y los registradores buscan casos adicionales en fuentes como anatomía patológica, laboratorios, egresos hospitalarios, certificados de defunción e historias clínicas." %}
  2. {% translate "Registro en la unidad informante:" %} {% translate "se confeccionan y codifican los reportes, se revisan las fuentes y se introducen los casos en el sistema automatizado del Registro." %}
  3. {% translate "Revisión provincial:" %} {% translate "los equipos territoriales cotejan reportes y bases de datos, verifican variables y códigos, solicitan correcciones y coordinan las unidades informantes." %}
  4. {% translate "Cierre y remisión:" %} {% translate "las provincias preparan los cierres estadísticos y remiten al nivel central los casos nuevos validados junto con la documentación requerida, según el calendario estadístico." %}
  5. {% translate "Validación central:" %} {% translate "la Oficina Central revisa integridad y consistencia, investiga posibles duplicados o tumores múltiples, contrasta la información con mortalidad y solicita aclaraciones cuando son necesarias." %}
  6. {% translate "Consolidación y estadísticas:" %} {% translate "solo los casos validados se incorporan a la base consolidada; con ellos el RNC prepara y emite resultados estadísticos." %}

{% translate "En la organización descrita por la copia histórica, cada comisión provincial asesora al Director Provincial de Salud sobre el control del cáncer y el funcionamiento del sistema de información. La integran perfiles de coordinación de cáncer, oncología, estadística, epidemiología, hospitales y especialistas o técnicos de los hospitales que diagnostican casos. Su función es exigir y controlar el cumplimiento de los procedimientos, cuidar la calidad y continuidad del dato primario, emitir estadísticas provinciales preliminares y promover investigaciones epidemiológicas y clínicas." %}

{% translate "Los procedimientos describen frecuencias distintas para las tareas locales, la revisión territorial y los cierres al nivel central. El calendario concreto puede variar y debe consultarse en la edición vigente del Manual." %}

{% translate "Este flujo corresponde al trabajo del Registro. El portal público es una herramienta de consulta de resultados agregados y no recibe reportes de casos ni sustituye los sistemas internos del RNC." %}

{% translate "Coordinación nacional" %}

{% translate "Oficina central" %}

{% translate "La Oficina Central dirige técnicamente el sistema nacional, controla los procedimientos y la calidad de la información, ofrece asesoría metodológica y produce estadísticas. Recibe los cierres territoriales y coordina su validación y consolidación." %}

{% translate "El Manual RNC VII describe tareas centrales como comprobar la consistencia y completitud de los datos, revisar codificaciones, investigar duplicados y múltiples primarios, cotejar casos con información de mortalidad, pedir aclaraciones a los territorios e incorporar a la base consolidada solo los casos validados." %}

{% translate "El Manual también describe funciones de control de calidad, análisis de datos, informatización, procesamiento y edición, además de una Comisión Técnica Asesora para cambios a los procedimientos administrativos y técnicos." %}

{% translate "Guía de interpretación" %}

{% translate "Métodos y cálculos estadísticos" %}

{% translate "Las fórmulas siguientes explican conceptos usados en epidemiología descriptiva y en referentes internacionales. Para que un resultado del portal sea oficial, el RNC debe confirmar el método, las agrupaciones, los denominadores y las reglas de presentación aplicables al corte." %}

{% translate "Frecuencia relativa" %}

{% translate "Expresa qué parte de un total corresponde a una categoría:" %}

{% translate "porcentaje = (casos de la categoría / total de referencia) × 100" %}

{% translate "El total puede depender de la pregunta y de la unidad de análisis. El tratamiento de valores desconocidos, categorías excluidas y redondeo requiere una regla explícita; no se debe asumir que tumor y persona son unidades intercambiables." %}

{% translate "Tasa cruda de incidencia" %}

{% translate "Relaciona los casos nuevos observados con la población correspondiente al mismo período y territorio:" %}

{% translate "tasa cruda = (casos nuevos / población correspondiente) × 100 000" %}

{% translate "La escala por 100 000 es una forma habitual de presentación. Numerador, período, territorio, sexo, grupo de edad y población deben coincidir. El proyecto identifica la población residente de ONEI como denominador de trabajo; la serie, edición y convención temporal exactas deben quedar identificadas con el RNC." %}

{% translate "Tasa específica por edad" %}

{% translate "Aplica la misma razón dentro de cada grupo etario:" %}

{% translate "tasa específicaᵢ = (casos nuevosᵢ / poblaciónᵢ) × 100 000" %}

{% translate "El subíndice" %} i{% translate " representa un estrato de edad (y cualquier otra dimensión que se mantenga fija). Comparar estratos exige que la definición de grupo y el período sean consistentes." %}

{% translate "Tasa ajustada directamente por edad" %}

{% translate "Resume tasas específicas aplicando los pesos de una población estándar:" %}

{% translate "tasa ajustada = Σ (peso estándarᵢ × tasa específicaᵢ) / Σ (peso estándarᵢ)" %}

{% translate "El estándar es una población de ponderación, no el denominador de los casos. Como referencia metodológica de trabajo se estudia la estándar mundial Segi–Doll de 18 grupos quinquenales; el RNC debe validar su correspondencia, fórmula operativa, grupos abiertos, datos faltantes y redondeo antes de atribuirle cifras oficiales. Las comparaciones solo son interpretables si usan el mismo estándar y definiciones compatibles." %}

{% translate "Tasa indirecta e intervalos de confianza" %}

{% translate "La estandarización indirecta suele comparar los casos observados con los esperados según tasas de referencia por estrato. La elección de esas tasas de referencia y la forma de presentar el resultado requieren una definición institucional." %}

{% translate "Los intervalos de confianza describen incertidumbre estadística y dependen del indicador, el volumen de casos y el método elegido. Su incorporación al portal es una propuesta de trabajo, no una regla aprobada por el RNC. El método de tasa indirecta y el de intervalos permanecen pendientes de validación." %}
